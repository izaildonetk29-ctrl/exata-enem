## Publicação
Envie todos os arquivos para a raiz do repositório. No GitHub, use Settings → Pages → Deploy from a branch → main → /(root).

## Observação
As provas oficiais do ENEM são acessadas por link para o INEP. O site não reproduz integralmente os cadernos oficiais.
