# Exata ENEM

Site de Matemática e Ciências Exatas voltado para preparação para o ENEM.

## Como Publicar No GitHub Pages

1. Extraia todos os arquivos deste projeto.
2. Abra o repositório do GitHub.
3. Envie os arquivos para a raiz do repositório.
4. Vá em **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch **main** e a pasta **/(root)**.
7. Clique em **Save**.

O arquivo `index.html` deve ficar diretamente na raiz do repositório.

## Estrutura

- `index.html` — página inicial
- `lembretes.html` — concentração e uso de redes sociais
- `questoes.html` — área de questões
- `simulado.html` — simulado autoral
- `enem-oficial.html` — acesso às provas oficiais do INEP
- `formulas.html` — fórmulas
- `conteudos.html` — mapa de conteúdos
- `estrategia.html` — estratégia de prova e TRI
- `ferramentas.html` — calculadoras
- `style.css` — visual e animações

As questões oficiais são acessadas por links para o INEP, em vez de serem reproduzidas integralmente no site.
